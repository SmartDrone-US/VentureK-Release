Installing by hand

  1. Open this page on the controller and tap Download APK.
  2. If Android refuses to open it, allow installs from this source when prompted.
  3. Open the downloaded file and install over the existing app.

Installing over the top keeps your saved missions. Every release is signed with the same key, so Android treats it as an update rather than a different app.

Venture checks for updates itself at launch and offers to install them, so this page is only needed for a first install, or when the controller could not reach the internet at the time. The manifest it reads is version.json, beside this page.
